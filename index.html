// Zoom — TRIXIFILMS

TRIXIFILMS — suivi de films

L'ambiance Letterboxd, avec un twist vidéo (shorts de bandes-annonces) au scroll vertical.

01 —

Catalogue & recherche

Des milliers de films et séries. Recherche par titre, réalisateur, acteur, production ou mots-clés du résumé. Filtres par genre et origine combinables.

02 —

Fiches détaillées

Synopsis, fiche technique (année, durée, pays, note IMDb, genres), équipe et distribution avec photos. Filmographie complète en un appui. Saisons et épisodes pour les séries.

03 —

Short — flux de bandes-annonces

Un flux vertical de bandes-annonces, chargées automatiquement par lots, mêlant les genres. Glisse vers le bas pour la suivante, un bouton flottant permet d'y accéder depuis n'importe quelle page.

04 —

Notes & discussions

Chaque film possède sa page de discussion. Notes de 1 à 5 étoiles et messages. Le serveur force le vrai pseudo du compte — pas d'usurpation possible.

05 —

Top de la communauté

Les meilleurs films du moment, classés selon les notes de la communauté. Ajoutez-y vos coups de cœur.

06 —

Box — collections partagées

Créez des collections de films, publique ou privée. Chaque Box possède un code unique à 8 caractères à envoyer à vos amis. Seul le propriétaire gère le contenu.

07 —

Compte sécurisé

Inscription en quelques secondes (pseudo + mot de passe). Session persistante, mots de passe hachés et connexion chiffrée entre l'app et le serveur.

08 —

Mises à jour automatiques

L'app vérifie automatiquement les nouvelles versions et propose de les installer en un appui. Vérification manuelle possible depuis les paramètres. Android 7.0+.

Télécharger l'APK→ Voir sur GitHub (open source)→

// Zoom — Hagar Auth OPEN SOURCE

Hagar Auth — clé en main

Vous créez un projet, définissez vos champs, et l'app génère des formulaires d'inscription/connexion prêts à intégrer. Pas de backend à écrire : vous déposez les fichiers générés et l'authentification fonctionne.

Avantages

  • Clé en main — aucun backend à écrire, déposez les fichiers générés et c'est prêt
  • Champs personnalisables — définissez la structure des utilisateurs (texte, email, mot de passe, nombre, date, etc.)
  • Sécurisé — mots de passe hachés (Argon2id), jamais stockés en clair ni renvoyés par l'API
  • Tableau de bord — consultez la liste des inscrits de chaque projet, avec date d'inscription
  • Clé API par projet — chaque projet possède sa propre clé et sa propre structure
  • Rate limiting & CSRF — protection brute-force, CSRF sur toutes les actions, CORS limité, HTTPS forcé en production

// Hagar Auth — inscription (fichiers générés)
// 1. Créez votre projet sur hagar-auth.vercel.app
// 2. Téléchargez inscription.html + connexion.html
// 3. Hébergez-les sur votre site — c'est tout.

// Appel API direct (si intégration sur mesure) :
const res = await fetch("https://hagar-auth.vercel.app/api/hagar/register", {
  method: "POST",
  headers: {
    "Content-Type": "application/x-www-form-urlencoded",
    "X-Hagar-Token": "votre-cle-api-projet"
  },
  body: new URLSearchParams({
    "Pseudo": "client",
    "Mot de passe": "azerty12"
  })
});
const data = await res.json();
// 201 → créé · 400 → validation · 401 → jeton invalide
console.log(data);
// Routes : POST /api/hagar/register · POST /api/hagar/login — Limites : 30 req/min/IP
01 —

Créer un compte admin

Allez sur /register, choisissez un pseudo et un mot de passe fort (12+ caractères, 3 catégories). Connectez-vous via /login.

02 —

Créer un Hagar

Nommez votre projet, définissez la structure des champs (le premier sert d'identifiant, un champ Mot de passe est obligatoire).

03 —

Clé API & fichiers

Récupérez la clé API (affichée une seule fois), puis téléchargez inscription.html, connexion.html et hagar_config.js.

04 —

Intégrer & suivre

Hébergez les fichiers sur votre site. Consultez les inscrits depuis le tableau de bord (Voir les utilisateurs).
