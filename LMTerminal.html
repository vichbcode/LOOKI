// Fonctionnalités

Un terminal complet et vivant

Tout ce qu'on attend d'un terminal moderne, avec une personnalisation poussée.

01 —

Totalement personnalisable

Thèmes, couleurs, polices, disposition : ajustez chaque détail du terminal selon vos préférences.

02 —

Complet

Toutes les commandes et fonctionnalités attendues d'un terminal sérieux, réunies au même endroit.

03 —

Setup x64

Installation simple et rapide sur les processeurs Intel/AMD 64 bits grâce au programme d'installation.

04 —

Version ARM64

Build dédié pour les appareils Windows à processeur ARM, pour des performances natives.

Pourquoi LMTerminal ?

  • Personnalisation totale — le terminal s'adapte à votre façon de travailler
  • Version complète — pas de version édité, tout est inclus
  • Deux architectures — Setup x64 et ARM64 pour couvrir tous les PC Windows
  • Présenté par LOOKI — même exigence de qualité que nos autres apps
LMTerminal — aperçu 
PS C:\Users\looki> LMTerminal --version
LMTerminal v1.0 — édition complète

PS C:\Users\looki> LMTerminal --theme nord
> thème appliqué : nord

PS C:\Users\looki> LMTerminal --font "JetBrains Mono"
> police mise à jour : JetBrains Mono

PS C:\Users\looki>
